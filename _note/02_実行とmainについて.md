## 実行とmainについて

 * カレントディレクトリに package main は複数配置できる。
 * package main が複数ファイルにまたがっていても、その中で「func main()」は１つだけ存在できる。
 * 「go run .」を実行すると、カレントディレクトリの「package main」を探し、その中の「func main()」を実行する。
 * package は複数ディレクトリにまたがる事はできない。
 * ディレクトリ単位でバイナリが作成される。
 * カレントディレクトリ以外の処理を使いたい場合、import する。
 * 単独の実行プログラムではないユーティリティなどは func main は不要。
